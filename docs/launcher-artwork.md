# Launcher artwork

Generated with the built-in image-generation tool, then resized and compressed
with Sharp. Originals remain in the local generated-images directory. The app
uses `public/launcher/le-morne.webp`, `home.webp`, `car.webp`, and `care.webp`.
All labels, navigation, card surfaces, lighting overlays, and interactions are
implemented in HTML/CSS/React. The artwork is raster-rendered 3D, with CSS depth
and animation; this page does not load WebGL.

## Hero prompt

Use case: stylized-concept. Create a single cinematic landscape artwork for a premium Mauritian technology website hero, wide 1536x1024 composition. Photorealistic 3D diorama of Le Morne Brabant Mauritius, recognizable dramatic flat-topped rocky green mountain rising from a tiny lush tropical island, turquoise lagoon and dark navy ocean, glowing fine electric cyan orbital trails looping around the island, atmospheric luminous clouds, midnight blue sky. Mountain centered, occupying middle 65 percent, ocean below, generous dark nearly black navy edges to seamlessly blend into #03111d website. Premium realistic materials, beautiful volumetric blue light, detailed tropical vegetation, subtle science fiction connectivity. No text, no logos, no interface, no phone frame. This is a background artwork only; all website text and controls will be real HTML.
